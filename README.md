# 🪑 CHARIVARI HOME — Ladislav Tobiášek

Oficiální webová prezentace rodinné čalounické a restaurátorské dílny **CHARIVARI HOME** (Ladislav Tobiášek, Nová Ves 22 u Mělníka).

## ✨ Hlavní sekce webu

1. **Zážitkové kurzy čalounění a renovace:**
   - **Kurz Renovace a čalounění nábytku** (`3 300 Kč`, celodenní kurz cca 8 hodin s vlastním kusem nábytku).
   - **Kurz Výroba čalouněného taburetu** (`3 900 Kč`, celodenní kurz 8 hodin — výroba od dřevěného korpusu po čalounění).
   - Přímá online rezervace volných termínů přes integrovaný rezervační systém **Reservanto**.
2. **Zakázkové restaurování a čalounění:**
   - Tradiční čalounické postupy (ruční vyvazování pružin, africká tráva, koňské žíně, lněné popruhy) a šelaková politura dřeva.
3. **Autoveteráni a motocykly:**
   - Renovace sedel motocyklů a kompletní čalounění interiérů historických vozů (sedadla, dveřní výplně, stropnice).
4. **Dárkové poukazy s konfigurátorem věnování:**
   - Interaktivní náhled dárkového voucheru s vlastním věnováním a přímou objednávkou.
5. **Rodinná historie (3. generace čalouníků):**
   - Archivní fotografie a příběh rodinné tradice sahající do 30. let 20. století v Praze 7 – Holešovicích (praděda František a děda Ladislav).
6. **Interaktivní fotogalerie realizací** s filtrováním podle kategorií a lightbox prohlížečem.

## 🚀 Lokální spuštění a produkční build

```bash
cd /Users/tobioli/charivari-home
npm install
npm run dev      # vývojový server
npm run build    # produkční build do složky dist/
```
